# Security policy

PHASEFORM is a pre-1.0 draft format with a reference toolkit (`packages/`). There are no supported versions and no support guarantees.

To report a vulnerability, please do not open a public issue. Use a private [GitHub security advisory](https://github.com/SantasLair/phaseform/security/advisories/new) on this repository. Include what you found, how to reproduce it, and which file or package it affects.
