# Using the PHASEFORM name

The code and the specification are openly licensed (see [README](README.md#license)). The name is not: those licenses grant no rights to the name PHASEFORM. This page says how you may use it, so that "PHASEFORM" keeps meaning one format that tools can rely on.

## You may

- **Say your tool supports the format:** "supports PHASEFORM", "imports and exports PHASEFORM", "reads PHASEFORM scenes".
- **Say your tool is compatible:** "PHASEFORM-compatible". Use this only if your tool passes the parts of the [conformance suite](conformance/README.md) that apply to it, and say which spec version it supports (for example "PHASEFORM 1.0-compatible").
- **Refer to the project** in articles, talks, tutorials, documentation and comparisons.
- **Credit a fork or derived format** with "based on PHASEFORM" or "derived from PHASEFORM", as long as it has its own name.

## Please do not

- **Name a modified format PHASEFORM,** or anything easily confused with it (such as "PHASEFORM Plus" or "PhaseForm 2"). A changed spec needs its own name.
- **Write `"format": "phaseform"`** in files that do not follow the spec. That value is how tools recognize the format.
- **Imply endorsement:** do not suggest that the PHASEFORM project made, reviewed, certified or recommends your tool, unless it has.
- **Use the name as your product's name** or as part of it (such as "PHASEFORM Studio").

## Questions

If you are unsure whether a use is fine, open an issue on the project's repository and ask.
